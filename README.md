# C# Projects

Here are the sample projects I have worked on.

- [IncomeComparisionProgram](#incomecomparisionprogram)

## CarInsurance

This project is an ASP.NET Core MVC application designed to collect customer insurance information, calculate a quote, and store data using a database-backed workflow. It demonstrates form handling, model validation, database integration, and the use of Entity Framework with ASP.NET Core.

## IncomeComparisionProgram

This console application compares the annual income of two people based on their hourly rate and hours worked per week. It highlights basic C# programming concepts such as user input, arithmetic operations, type conversion, and conditional logic for decision-making.

## StudentEFConsoleApp

This project is a console application that uses Entity Framework Core to add student records to a database. It shows how to create data models, connect to a database, capture user input, and save information in a persistent and structured way.

## DailyReportAssignment

This assignment is a student daily report console app that gathers information such as the student’s name, course, page number, questions for help, positive experiences, feedback, and study hours. It demonstrates input collection, string handling, data conversion, and simple console-based interaction in C#.
